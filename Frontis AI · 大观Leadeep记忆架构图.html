核心判断

Leadeep 和飞书不是独立会话体系，只是进入大观 Web 指定会话的入口；两者唯一差异是页面展示的对话记录同步方向。

同步方向

Leadeep 与 Web 绑定会话双向同步页面聊天记录；飞书只把飞书对话记录同步到 Web，Web 续聊不回飞书。

其他能力一致

长期个人记忆、文件线索、任务记忆和 Agent 配置按同一套绑定会话机制生效，不再为飞书另设一套规则。
