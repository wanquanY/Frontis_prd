S2
创建 FDE 组织与账号
运营/admin 创建 FDE 团队组织，邀请 FDE 工程师加入，配置角色权限（团队负责人/小组负责人/普通成员）
角色：运营 / Platform Admin
⬇
二Agent 开发与上架（Agent Store）
S3
开发者开发 Agent
在 Agent 工作空间开发 Agent，关联 Skill、配置模型、绑定 Runtime，测试完成后提交到 Agent Store
角色：开发者（FDE 或外部开发者）
S4
运营审核 Agent
查看 Agent 信息、版本说明、性能报告、风险评估 → 审核通过进入 Agent Store / 驳回告知原因
角色：运营
⬇
三🟥 商品化与定价（商品中心）
🔴 核心变更：Agent 审核通过后只是"技术资产"，必须经过运营商品化才能成为可售卖商品。定价权在运营，不在开发者。
S5
🟥 Agent 转为商品
从已审核 Agent 列表点击"转为商品"，填写商品信息（名称/描述/类目/标签/封面），设置定价（固定价/免费/试用）、有效时长、试用天数 → 上架
角色：运营
S6
🟥 创建设备/资源包商品
直接在商品管理中新建设备商品（云端工作站/本地工作站/本地客户端）和积分包商品，填写规格和定价 → 上架
角色：运营
S7
🟥 创建组合商品
AI 专家团：从已上架 Agent 商品中选多个打包定价
促销套餐：多基础商品（设备+Agent+积分+服务）打包，独立定价
角色：运营
↓
S8
🟥 商品上下架管理
商品列表查看所有商品 → 上架（出现在商品池）/ 下架（不再展示，历史订单不受影响）/ 编辑（调价需记录日志）/ 归档
状态流转：草稿 → 在售 → 已下架 → 重新上架 或 归档
角色：运营
✅ 阶段三完成后：商品池就绪，所有可售商品已上架，FDE 可以开始选品下单。
⬇
四商机 → 租户 → 下单
S9
商机/线索获取
来源：营销门户自动同步 / FDE 线下沟通手动录入 / 其他渠道导入
记录：企业名称、业务场景、行业、需求联系人、预计金额、感兴趣 AI 专家、需求描述
角色：FDE / 系统
S10
商机跟进与分配
团队负责人分配商机给小组或成员 → FDE 跟进（沟通/演示/方案/商务）→ 状态流转：未开始 → 对接中 → 已成单
角色：FDE 团队负责人 / FDE 工程师
↓
S11
创建租户
FDE 在租户管理中创建客户企业租户，填写企业信息（名称/行业/管理员联系方式），邀请企业管理员加入
角色：FDE 工程师
💡 会议确认：必须先有租户，才有订单。顺序：商机 → 租户 → 选商品 → 订单
↓
S12
🟥 浏览商品池选品
FDE 进入商品列表（Marketplace），查看可售商品（运营已上架）
按类目筛选：AI 能力 / 设备 / 资源包 / 套餐
搜索商品 → 查看商品详情和价格
角色：FDE 工程师
↓
S13
🟥 创建订单
正确流程（改造后）：
1. 在租户下点击「新建订单」
2. 从商品池选择商品（已带运营定价）
   🟡 AI Agent × 1 ¥9,800
   🟡 AI 专家团 × 1 ¥28,000
   🟡 云端工作站 × 2 ¥19,600
   🟡 积分包 × 1 ¥5,000
3. 确认商品清单和总价 → 填写备注 → 创建订单
角色：FDE 工程师
🔴 与现有流程区别：现有 = 先建空订单再手动加商品行 → 改造后 = 从商品池选商品 → 确认清单 → 自动生成订单。商品价格由运营预设，FDE 不手动填单价。
⬇
五付款 → 交付 → 资产
S14
线下付款确认
客户线下付款（扫码/转账等），FDE 在订单中将付款状态更新为「已付款」，可上传付款凭证（二期完善）
角色：客户 / FDE 工程师
S15
🟥 配置交付（商品 → 资产）
订单中的🟥商品信息自动带入交付步骤：
设备分配 → 确认设备额度、生效时间
Agent 下发 → 按订单商品下发 Agent，从 Agent Store 下载（下载记录必须关联订单）
企业后台配置 → 引导管理员完成权限配置
交付验收 → 检查清单确认
角色：FDE 工程师
↓
S16
🟥 形成客户资产
交付完成后，🟥订单中的商品转化为客户资产：
🟡 设备商品 → 设备资产（资产 ID + 到期时间）
🟡 AI 专家团 → AI 专家资产（团内每个 Agent 独立资产）
🟡 积分包 → 积分额度
角色：系统自动
⬇
六企业运营 & 续费/增购
S17
企业管理员自主运营
管理员工权限（谁能用哪些 AI 专家）、查看设备状态、配置模型供应商、处理设备绑定
角色：企业管理员
S18
AI 专家版本运营
FDE 检测租户下 Agent 是否有新版本 → 推送升级 → 企业管理员决定是否接受 → 支持忽略/回退 → 查看版本历史
角色：FDE / 企业管理员
↓
S19
🟥 资产续费 & 增购
资产即将到期 / 客户需要扩容 → 创建续费/增购订单（不是直接改时间）
🟡 选择要续费的商品 → 付款 → 交付 → 更新到期时间
续费 = 新订单 → 新交付 → 新到期时间
角色：FDE / 客户

📌 关键业务规则

🟥 定价权在运营
开发者不定价，运营审核通过后决定卖不卖、卖多少钱
🟥 一个 Agent 可对应多个商品
同一 Agent 可创建标准版/企业版/试用版等不同商品
🟥 订单存快照
下单时价格/规格快照保存，后续调价不影响历史订单
💡 先有租户才有订单
会议确认：商机 → 租户 → 选商品 → 订单
💡 下载必须关联订单
所有 Agent 下载/分发必须挂在订单上，否则无法管控
🔄 续费走新订单
不是直接改到期时间，而是新订单 → 新交付 → 更新时间
