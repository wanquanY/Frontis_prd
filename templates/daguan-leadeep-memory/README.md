# 大观 Leadeep 统一记忆机制模板说明

本目录用于定义大观 Web、Leadeep 问策和后续飞书绑定入口共用的 ME 记忆文件体系。这里的文件名是产品口径，研发实现可以映射为结构化表、配置中心、对象存储或索引服务，但文件职责不能混用。

统一记忆文件按 `User + Tenant + Member + Agent` 隔离。每个用户使用的每个 Agent 都有一套独立文件，不同 Agent 默认不共享用户画像、专家团队、长期记忆、文件线索、session 上下文或配置。

## 文件总览

| 文件              | 职责                                                                                      | 作用范围                                   | 跨会话   | 与页面历史记录的关系         |
| ----------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------ | -------- | ---------------------------- |
| `Agent.md`        | 定义当前 Agent 对当前用户生效的稳定身份、角色边界、表达风格和禁止事项                     | `User + Tenant + Member + Agent`           | 是       | 不保存历史记录               |
| `team.md`         | 定义当前 ME 工作台已添加专家的团队清单、专家 ID、能力画像摘要、工作台状态和详情引用       | `User + Tenant + Member + Agent`           | 是       | 不保存历史记录               |
| `user.md`         | 定义当前用户在当前 Agent 下的画像、租户成员身份、工作角色和稳定偏好                       | `User + Tenant + Member + Agent`           | 是       | 不保存历史记录               |
| `memory.md`       | 定义当前用户使用当前 Agent 时形成的长期记忆条目，包括偏好、目标、纠错、任务结论、对象事实 | `User + Tenant + Member + Agent`           | 是       | 从历史中提炼，不等于历史原文 |
| `session.md`      | 定义当前 Agent 的单个会话短期任务上下文、当前目标和待确认问题                             | `User + Tenant + Member + Agent + Session` | 默认否   | 可由当前历史记录提炼         |
| `file-index.md`   | 定义当前用户使用当前 Agent 时可召回的文件线索、文件摘要、来源、权限和召回标签             | `User + Tenant + Member + Agent`           | 按权限是 | 记录文件索引，不保存文件全文 |
| `agent-config.md` | 定义当前 Agent 对当前用户生效的专家、工具、能力开关、调用偏好和渠道能力约束               | `User + Tenant + Member + Agent`           | 是       | 不保存历史记录               |

## 组装规则

1. `Agent.md` 先确定当前 Agent 对当前用户生效的身份和边界。
2. `agent-config.md` 决定可用能力、专家和工具策略。
3. `team.md` 提供当前 ME 工作台已添加专家清单和能力画像摘要。
4. `user.md` 提供当前用户与租户成员画像。
5. `memory.md` 提供可跨会话召回的长期记忆。
6. `file-index.md` 提供可定位、可引用的文件线索。
7. `session.md` 提供当前会话短期任务上下文。
8. 页面历史记录只作为当前绑定 session 的消息流参与当前对话。

## 同步规则

- Leadeep 绑定会话与 Web 历史记录双向同步，指页面可见的消息、引用文件、输出产物和状态同步。
- 飞书绑定会话只从飞书单向同步历史记录到 Web，Web 续聊不回写飞书。
- Web、Leadeep、飞书使用同一套记忆文件体系，差异只在历史记录同步方向。
- 记忆文件不等于历史记录。历史记录原文不能无控制地跨 session 召回。
- 不同 Agent 的记忆文件默认隔离；跨 Agent 共享或复制必须另行设计授权、范围和审计规则。
- `team.md` 由工作台专家添加、移除和专家配置变更事件自动同步，不由普通聊天内容自动改写。
