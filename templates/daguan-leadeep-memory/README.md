# 大观 Leadeep 统一记忆示例模板

这个目录是一组模拟真实使用后的 ME / Agent 文件。

示例场景：产品经理王晨在 Web 端写大观 V1.1 PRD，出差时用 Leadeep 问策追问历史 PRD 内容，飞书对话记录后续单向同步到 Web。ME 通过这些文件持续理解用户、任务、文件线索、专家团队和渠道配置。

## 文件

- `Agent.md`：当前 ME 产品助手的工作身份、产品边界和禁止事项。
- `user.md`：王晨的工作画像、表达偏好和近期纠正。
- `memory.md`：已经沉淀的长期偏好、产品规则、迁移规则和可复用结论。
- `session.md`：当前 Leadeep 问策同步会话的短期任务状态。
- `file-index.md`：当前可召回的 PRD、需求列表、原型和代码文件线索。
- `team.md`：当前 ME 工作台已添加专家的能力画像和专家 ID。
- `agent-config.md`：当前 Agent 对 Web、Leadeep、飞书三个入口生效的工作配置。

这些文件用于产品评审时说明“真实运行时 Agent 会看到什么”。
