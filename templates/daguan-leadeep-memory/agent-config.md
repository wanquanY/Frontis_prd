# agent-config.md

## 文件定义

`agent-config.md` 定义当前用户使用当前 Agent 时生效的专家、工具、能力开关、调用偏好和渠道能力约束。它决定 Agent 如何工作，但不保存用户聊天原文，也不保存长期记忆事实。

## 作用范围

- agent_id:
- tenant_id:
- user_id:
- member_id:
- effective_channels: web / leadeep / feishu
- version:
- updated_at:
- updated_by:

## 隔离规则

- 本配置只对当前 `tenant_id + user_id + member_id + agent_id` 生效。
- 不同 Agent 的配置默认隔离，不直接复用工具策略、专家偏好或渠道能力约束。
- 如需复制配置，必须记录来源 Agent、目标 Agent、复制人和生效时间。

## 专家与能力

| 能力         | 状态     | 适用渠道     | 调用条件                    | 备注 |
| ------------ | -------- | ------------ | --------------------------- | ---- |
| PRD 专家     | enabled  | web, leadeep | 用户询问产品方案、需求、PRD |      |
| 数据分析专家 | disabled | web          | 待确认                      |      |

## 工具策略

| 工具     | 状态    | 触发规则                   | 权限要求            | 失败处理                       |
| -------- | ------- | -------------------------- | ------------------- | ------------------------------ |
| 文件检索 | enabled | 用户询问历史文件或引用内容 | 文件可见权限        | 提示无法读取或要求用户选择文件 |
| 文档导出 | enabled | 用户明确要求输出文档       | 当前 session 写权限 | 返回失败原因并支持重试         |

## 渠道能力约束

| 渠道    | 可创建 session | 历史记录同步            | 可使用记忆 | 可使用文件线索 | 特殊限制                |
| ------- | -------------- | ----------------------- | ---------- | -------------- | ----------------------- |
| web     | 是             | 当前 Web session 内读写 | 是         | 是             | 多 session 主入口       |
| leadeep | 否             | 与 Web 绑定会话双向同步 | 是         | 是             | 只进入 Leadeep 绑定会话 |
| feishu  | 否             | 飞书到 Web 单向同步     | 是         | 是             | Web 续聊不回写飞书      |
